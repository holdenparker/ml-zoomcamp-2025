# Midterm
I decided to build an ML model to predict what a good salary would be for an individual.

## Getting started
This project utilizes Docker Compose to build and orchestrate containers.
This includes both the service and the jupyter notebook.
**To view the jupyter notebook and build the service, run the following command:**

```sh
docker compose -f docker/docker-compose.yml up -d midterm
```

The password to the jupyter notebook is `jupyter`, not a randomly generated token.
To access the notebook, open your browser to [http://localhost:6593/](http://localhost:6593/).
The easiest way to run all of my research, including a test command to the isolated service, is to select the **Restart the kernel and run all cells** ⏩ button.

## Using the service
The last cell in the `midterm.ipynb` notebook includes an easy-to-use setup to test with different known values.
However, you can also use a tool like `curl` to test the service:

```sh
curl -X POST \
  -H "Content-Type: application/json" \
  -d '{"age": 28, "gender": "Male", "education_level": "phd", "job_title": "Director", "years_of_experience": 15.0}' \
  http://localhost:9696/predict
```

> **Note:** In the jupyter notebook, you will see the url is `http://midterm-service:9696` while `curl` uses `http://localhost:9696`.
> We use `midterm-service` because the jupyter notebook and the service are both deployed in docker and share a docker network.
> We can use `localhost` with `curl` because I've exposed the `9696` port in the `docker-compose.yml` file.

## Files
Here is an accounting of the different files in this project:
- `.python-version` _A file generated by uv._
- `main.py` _The python file defining the Flask service._
- `midterm.ipynb` _The jupyter notebook containing my model research and tuning, along with a test command for convenience._
- `pyproject.toml` _A file generated by uv._
- `README.md` _The file you're currently reading, that I'm hoping is helpful._
- `requirements.txt` _The base dependencies used by docker to build the jupyter notebook and start building the service._
- `Salary_Data.csv` _The data I'm using for the project, sourced from [kaggle/salary-dataset](https://www.kaggle.com/datasets/mubeenshehzadi/salary-dataset)._
- `train.py` _The final training script used to train and export the model._
- `uv.lock` _A file generated by uv._

## Related files not in the midterm directory
Here is an accounting of files used by the Midterm project that live elsewhere.
- `docker/docker-compose.yml` _The Docker Compose definition file, allowing for easy and consistent deployment of containers to docker._
- `docker/Dockerfile.jupyter` _Defines the jupyter notebook environment.  Includes targets for `homework` and `midterm`.
- `docker/Dockerfile.midterm` _Defines the service image to be deployed by Docker Compose._
